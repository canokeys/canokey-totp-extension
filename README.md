# CanoKey TOTP

CanoKey TOTP fills two-step verification codes generated by your CanoKey. Use it in desktop Chrome or Edge (version 116 or later) with a CanoKey that has WebUSB enabled.

## Install and connect

1. Unzip the extension download.
2. Open `chrome://extensions` in Chrome or `edge://extensions` in Edge.
3. Turn on **Developer mode**, click **Load unpacked**, and choose the folder containing `manifest.json`.
4. Plug in your CanoKey. Open **CanoKey TOTP** from the browser’s extensions menu, click **Connect CanoKey**, and select your key in the browser prompt. You can also connect a key from **Settings → Devices → Authorize a CanoKey**.

## Fill or copy a code

- On the HTTPS verification page, press **Alt+Shift+O** (**⌥⇧O** on macOS). If the extension finds exactly one matching account and can read all authorized keys, it fills the code automatically. If an account picker opens, click **Fill code** on the account you want.
- You can also open **CanoKey TOTP** from the extensions menu and click **Fill code** or **Copy code** beside an account. This works on HTTPS sites without an issuer mapping.
- Enter your key’s **OATH access password** if prompted. Touch your CanoKey when the extension asks. Submit the verification form when the code is in place.

You can change the shortcut at `chrome://extensions/shortcuts` or `edge://extensions/shortcuts`.

## Show the C button on a website

1. Open **Settings → Issuer and websites**. Check **Built-in mappings** for the website. To add a mapping, enter the issuer as it appears on the CanoKey and the website’s HTTPS address, then click **Add mapping**. The hostname and port must match the verification page.
2. On any mapped website, open the extension and click **Show C on all mapped websites**. You grant access to all HTTPS websites in a single browser prompt. This covers any mappings you add later.
3. Click **C** beside the verification field to fill a code. The button appears on mapped websites with a recognized verification field.

If **C** is missing, check the mapping and the extension’s **Site access** setting in the browser, then reload the page. You can also use **Site access** to revoke the permission. The keyboard shortcut and the extension menu work with access to the current tab. An account with a blank issuer can still be filled from the extension menu by selecting it directly.

## Add an account

Open **CanoKey TOTP** and click **Add account**. If you’re setting up two-step verification on a website, open the extension from that page.

- For a setup QR code, make it visible in the current tab and click **Scan visible tab**.
- For a setup link, choose **Paste otpauth URI** and paste the complete link.
- For a setup key, choose **Manual entry** and enter the Base32 secret and the parameters shown by the service.

Review the account and issuer, select the CanoKey, and choose whether each code requires a touch. Click **Import to CanoKey**. If **Import and fill** is available, it saves the account and fills the code in one step.

## Troubleshooting

| What you see | What to do |
| --- | --- |
| CanoKey is unavailable or busy | Close other apps using the key, reconnect it if needed, and click **Refresh**. If the browser cannot see it, check that WebUSB is enabled on the key. |
| No TOTP credentials found | Add an account or connect the CanoKey that holds the account you need. |
| No verification field, or several fields | Focus the correct field and try again, or use **Copy code** and paste it into the form. |
| Code expired or the page changed | Start again on the verification page to generate a fresh code. |

## Privacy

Your CanoKey stores accounts and generates codes on demand. The extension reads accounts directly from the key and saves only your custom issuer mappings. QR scanning happens on your computer. When you fill or copy a code, it goes to the current webpage or your system clipboard.
